## Project Overview

Quant BDM is a **comprehensive stock analysis platform** specifically designed for the Indonesian stock market (IHSG). It combines technical analysis, bandarmology (broker analysis), and volume price analysis to provide deep market insights.

[View Repository on GitHub](https://github.com/milyas26/quant-bdm)

- **Technical Analysis**: Advanced charting with multiple indicators and price patterns.
- **Bandarmology**: Broker accumulation, distribution, and inventory analysis.
- **Volume Price Analysis (VPA)**: Smart money detection through volume and price relationship.
- **Stock Screener**: Filter and discover stocks based on custom criteria.

## Core Features

The platform provides professional-grade tools for stock market analysis:

- **Dashboard**: Overview of market conditions, watchlist stocks, and key metrics.
- **Stock Detail**: Comprehensive analysis view for individual stocks with charts and indicators.
- **Broker Analysis**: Track broker activities, accumulation patterns, and inventory levels.
- **Screener Analysis**: Filter stocks based on technical and fundamental criteria.
- **Watchlist**: Monitor selected stocks with real-time updates.
- **Demo Trading**: Practice trading with virtual capital before risking real money.

## Technical Architecture

Built with modern web technologies for optimal performance:

- **Vite**: Lightning-fast development server and optimized production builds.
- **React 19**: Latest React features for building interactive user interfaces.
- **TypeScript**: Type-safe development with full TypeScript support.
- **Tailwind CSS 4**: Utility-first CSS framework for rapid UI development.
- **Shadcn UI**: High-quality, accessible UI components.
- **Zustand**: Lightweight state management for global application state.
- **React Query**: Data fetching and caching for API interactions.
- **Chart.js & Recharts**: Advanced charting capabilities for financial data visualization.

## Analysis Capabilities

Quant BDM offers specialized analysis tools for the Indonesian market:

### Bandarmology Analysis
- **Broker Accumulation**: Track which brokers are accumulating specific stocks.
- **Broker Distribution**: Identify when brokers are distributing holdings.
- **Inventory Analysis**: Monitor broker inventory levels and changes.
- **Cohesion Analysis**: Analyze broker behavior patterns and coordination.

### Volume Price Analysis (VPA)
- **Smart Money Detection**: Identify institutional buying and selling patterns.
- **Whale Detection**: Track large volume transactions and their market impact.
- **Retail Exhaustion**: Recognize when retail investors are running out of steam.
- **Floor Price Analysis**: Determine support levels based on volume clusters.

### Technical Analysis
- **Historical Price Charts**: View price history with various timeframes.
- **Indicators**: Apply technical indicators for trend analysis.
- **Pattern Recognition**: Identify chart patterns for trading decisions.
